# 最近缩放跟随原版

读取当前游戏 `Core.getMinZoom()`，沿用原版当前启用的最近缩放档位。
本地游戏字节码中，`MultiTextureFBO2` 默认档位包含 0.25，实际最近档位由原版选项筛选；
`getMinZoom()` 返回已启用档位的末项，`Core.getMinZoom()` 还应用 tileScale / 2。
当前本机原版选项启用的最近档位是 0.5（2x 贴图）。

OldPoint 的 Layout 使用 `cameraZoom = 0.32 * distance / 100`，
以相机目标平面的图块比例为参照，换算下限为 `nativeZoom * 100 / 0.32`。
当前配置约为 156.25；界面以整数向上取整为 157。
这并不表示整幅透视画面能与原版正交投影逐点重合。

Java 在捕获缩放时更新原版下限，并限制 current、target 和 remembered。
滚轮和恢复逻辑共享同一 clamp，因此旧配置中的 minimumDistance=10 不再绕过原版最近端。
Lua 在游戏内应用设置时同步显示下限；主菜单不提前查询尚未初始化的原版 FBO 档位。
用户仍可设置更严格的最近端。最远端沿用现有设置，本机为 600；不以原版最远档位替换它。

近裁面默认仍为 2.0；缩放限制与近裁面独立。
