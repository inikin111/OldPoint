# 室内圆角削墙验证

目的：验证能否复用现有遮挡墙选择，仅改变 fragment 裁剪方式，让隐藏墙保留圆角轮廓和原材质。

## 改动

- `OcclusionRendering.upload` 上传 `uOPRoundedWalls`：仅已有俯视渲染启用、非室外且具有室内范围时启用。
- `OcclusionShaders` 的墙规则循环，在当前楼层的已选墙上，使用沿墙位置计算轮廓高度，裁掉轮廓上方的片元。
- 根据实际上传的遮挡墙集合，统计每个同楼层端点相接的墙数。直线、垂直转角和 T 形连接都算连续，相接处保持 lowHeight=0.1，不保留高端头；只有无其他选中墙相接的外端使用 L 形公式，终点镜像。孤立墙格两端均应用过渡。端点标志放在墙规则原有空闲分量，不增加缓冲区大小。
- 已移除原来的 rightRadius 和右端下降到地面的圆角，整个保留区高度不低于 lowHeight。参数位于 `oldPointRoundedWallHeight`：highHeight=1、lowHeight=0.1、leftX=0.125；上圆角横向宽度 topWidth=0.125、纵向高度 topHeightRadius=0.08333333；下凹圆角横向宽度 innerWidth=0.1875、纵向高度 innerHeight=0.08333333。
- 端部弧线参考游戏原版 `media/wallcutaways.png` 的轮廓比例拟合，横向墙宽与纵向层高分别归一化，不再共用单一半径。保留原有的 10% 矮墙高度；未复制原版描边和厚度着色，也不保证不同视角下的屏幕角度完全相同。
- 高度比例乘以 Viewpoint 楼层高度 2.4494896；水平参数以一格墙宽归一化，因此圆弧不保证在世界空间或画面上呈正圆。
- 复用已有 fade 进度，在完整墙高与目标轮廓之间插值。墙体选择、原贴图与光照继续使用既有流程。
- 其他楼层与室外仍走原墙面淡变。原有开口、屋顶、物体分类和面归属过滤先执行，当前验证不会覆盖这些提前返回的路径。

## 当前限制

按共享端点衔接直线、垂直转角和 T 形墙段；没有新截面封口、附属物同步裁剪或独立设置开关。渐变进度不同的墙在过渡过程中仍可能高度不一致。阴影规则保持现状。共享注入也覆盖已有远景及 Iris 接入点，但不宣称已经在所有光影包和游戏场景中验证。

## 验证

- Java 完整构建通过。
- 真实墙规则打包的 15 种排列检查通过：四种垂直转角、T 形连接、闭合墙圈、不同楼层的转角、零进度的转角邻墙，以及北墙连续段、西墙连续段、孤立墙、断开段、不同楼层/方向、零进度邻墙与部分渐变、负坐标乱序排列。修改前 corner start-start 检查失败，修改后全部通过。
- 既有 19 个镜头生命周期、7 个帧捕获、13 个绘制场景及 3 个 Hook 内联检查通过。
- Java 格式检查通过。
- 从实际 jar 读取 shader，使用产品中的源码转换并展开 include；glslangValidator 编译及链接通过 mesh/gbuffer、mesh/forward、far_shell/far_shell、far_shell/gbuffer_shell、mesh/puddle 五组基础 shader。该检查使用内置基础 shader 资源，不覆盖实际启用的所有光影包。
- 尚未完成游戏内观察；以上检查不能证明最终画面符合预期。

## 游戏内检查

1. 完全退出游戏后加载已部署版本，进入 OldPoint 俯视模式并走进普通房间。
2. 观察原本会消失的当前层墙面：应在渐变完成后，连续段中间留下平直矮墙，端部有 L 形过渡，不再有下沉到地面的右端圆角；原本不隐藏的墙保持完整。
3. 在室内移动、旋转视角，再走到室外，检查是否出现 shader 错误或墙体完全消失。
4. 本阶段仅判断圆角轮廓是否随既有选墙规则出现，不以封口、逐格接缝或装饰残留作为失败标准。
