# Third-party dependencies / 第三方依赖

OldPoint extends Project Zomboid and Viewpoint and uses ZombieBuddy's patch API. These projects are required to build or run the mod, but their binaries, source code, shaders, and assets are not distributed in this repository. OldPoint's GPL-3.0-only license applies to the original files in this repository; it does not relicense those dependencies.

OldPoint 依赖《Project Zomboid》、Viewpoint 和 ZombieBuddy 的接口。本仓库不分发这些项目的二进制文件、源码、光影或素材；OldPoint 的 GPL-3.0-only 协议不改变它们各自的授权。
